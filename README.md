# Заявки на транспорт

Учебная информационная база 1С: справочники, перечисление «Статусы заявки», документ «Заявка на транспорт» и три отчёта.

Платформа: 1С:Предприятие 8.3 (учебная версия), 8.3.8.1933.

## Как развернуть

1. Создайте новую пустую информационную базу и откройте её в Конфигураторе.
2. Выберите «Администрирование» → «Загрузить информационную базу» и укажите файл `TransportIB.dt`.

## Что в репозитории

- `TransportIB.dt` — выгрузка базы: конфигурация без данных.
- `src/` — конфигурация в виде файлов XML и BSL. Загружается через «Конфигурация» → «Загрузить конфигурацию из файлов».
